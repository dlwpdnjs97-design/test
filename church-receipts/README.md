# 초등부 영수증 자동 정리

구글 드라이브에 올린 영수증 사진을 Gemini가 읽어서 구글 시트 `출납장`에 자동으로 기록하고,
제출용 A4 출력물(PDF)까지 만들어 주는 Google Apps Script입니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `Code.gs` | 영수증 사진 읽기 → 출납장 기록, 메뉴, 문제 찾기용 함수 |
| `출력물.gs` | 출납장에서 고른 행의 영수증을 A4 한 장에 4장(또는 2장)씩 배치한 문서·PDF 만들기 |

## 폴더 구조 (구글 드라이브)

```
영수증 올리는 곳            ← Code.gs의 ROOT_FOLDER_ID
 ├─ 이OO                    ← 선생님 이름 폴더 (폴더 이름 = 출납장 '사용자')
 │   ├─ 생일                ← 항목 폴더: 여기 넣은 사진은 적요=생일, 비목=격려 및 시상
 │   │   └─ 처리완료        ← 읽은 사진이 자동으로 옮겨짐
 │   ├─ 심방
 │   ├─ 여름성경학교
 │   ├─ …                   ← 예산표 항목마다 하나씩 (메뉴로 자동 생성)
 │   └─ (여기 바로 넣은 사진은 AI가 적요를 추측)
 ├─ 강OO
 └─ 출력물                  ← 출력물 문서·PDF 저장 (영수증 읽기에서 제외)
```

- 항목 폴더는 시트 메뉴 **🧾 영수증 → 선생님 폴더에 항목 폴더 만들기**로 한 번에 만듭니다.
  선생님이 새로 오거나 예산 항목이 늘면 다시 누르면 없는 폴더만 추가됩니다.
- 폴더 이름은 예산표 적요와 맞춰 봅니다. 띄어쓰기와 괄호 속 날짜는 무시합니다
  (`여름성경학교` 폴더 = `여름성경학교(7/24금~25토)` 항목).
- `처리완료`, `출력물` 폴더는 자동으로 건너뜁니다.
- 폴더 이름 괄호 안에는 안내 문구를 넣어도 됩니다 (`오전간식(12월만 가능)` = `오전간식(빵)` 항목).
- 결제한 달에 예산표의 그 항목 칸이 비어 있으면 노란 줄로 **"○월에는 ○○ 예산이 없어요"** 경고를 남깁니다.

## 설치

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs`에 `Code.gs` 내용을 통째로 붙여넣고, 파일 **＋ → 스크립트**로 `출력물`을 만들어 `출력물.gs` 내용을 붙여넣기
3. ⚙️ **프로젝트 설정 → 스크립트 속성**에 아래 값 넣기 (코드는 고치지 않아요)

   | 속성 | 필수 | 값 |
   |---|---|---|
   | `GEMINI_API_KEY` | ✅ | aistudio.google.com 에서 받은 키 |
   | `ROOT_FOLDER_ID` | ✅ | `영수증 올리는 곳` 폴더 ID (드라이브 주소 `.../folders/` 뒤, `?` 앞까지) |
   | `BUDGET_SHEET` | | 예산표 탭 이름 (기본값 `2026 최종(고고고 변경내역)`) |
   | `MODEL` | | Gemini 모델 이름 (기본값 `gemini-3.5-flash-lite`) |
   | `CATEGORY_HINTS` | | 적요 판단 규칙, `;`로 구분 (예: `빵은 오전간식(빵); 과자·음료는 오후간식`) |

4. 함수 `setup`을 한 번 실행하고 권한 허용 → 10분마다 자동 실행 등록
5. 함수 `checkSetup`을 실행하면 설정값과 폴더 상태를 실행 로그에서 확인할 수 있어요.

**코드를 새 버전으로 바꿀 때**는 GitHub의 파일을 통째로 붙여넣기만 하면 됩니다. 설정은 스크립트 속성에 남아 있어요.

> ⚠️ API 키와 폴더 ID는 이 저장소에 올리지 않습니다. 저장소가 공개 상태입니다.

## 사용

- **영수증 처리**: 사진을 올리면 10분 안에 자동 처리. 바로 하려면 시트 메뉴 **🧾 영수증 → 지금 영수증 처리하기**
- **출력물**: 출납장에서 행을 드래그로 선택 → **🧾 영수증 → 영수증 출력물 만들기** → 비워 둔 채 확인
  (`출력물.gs`의 `PER_PAGE`를 `2`로 바꾸면 한 장에 2장씩 크게)
- **잔액**: 첫 줄 G열(수입금액)에 이월 잔액을 넣으면 '거래 후 잔액'이 맞게 계산됩니다.
- 노란 줄은 AI가 확인이 필요하다고 표시한 줄입니다. N열 'AI 메모'에 이유와 가게·품목 참고 정보가 있습니다.

## 문제가 생기면

| 실행 로그 | 해결 |
|---|---|
| 모델을 쓸 수 없어요 | `listModels` 실행 → 보이는 Flash 모델 이름을 스크립트 속성 `MODEL`에 넣기 |
| AI 서버가 바빠요(503) | 기다리면 자동 재시도 |
| 무료 사용량 한도 | 기다리면 자동 재시도 |
| 다른 실행이 아직 진행 중 | 5~10분 뒤 다시 실행 |
| 처리한 영수증: 0장 | `checkSetup` 실행해서 폴더에 사진이 보이는지 확인 |
